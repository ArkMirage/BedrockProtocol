# BedrockProtocol

[![License: MPL 2.0](https://img.shields.io/badge/License-MPL%202.0-brightgreen.svg)](LICENSE)
[![.NET](https://img.shields.io/badge/.NET-10.0-512BD4)](Protocol.csproj)

> [中文](README_ZH.md)

A pure C# implementation of the Minecraft Bedrock Edition network protocol, targeting .NET 10. It ships strongly-typed, ready-to-use codecs for every packet in the protocol — build servers, clients, proxies, and tools without hand-writing serialization code.

Targets Bedrock protocol version **2168** (see `ProtocolVersion.VERSION`).

Pairs naturally with our pure C# RakNet implementation, which handles the reliable UDP transport layer underneath the Bedrock protocol.

---

## Features

- **230+ packet codecs** — every registered packet gets a strongly-typed C# class implementing `Read` / `Write`
- **AOT-friendly registry** — `PacketRegistry` maps packet IDs ↔ types with plain dictionaries, no reflection
- **Generated code** — codecs are generated by [`Protocol.Gen`](https://github.com/ArkMirage) from protocol definitions
- **Zero-dependency binary IO** — span-backed `MemoryStreamReader` / `MemoryStreamWriter` and VarInt helpers
- **Faithful protocol modeling** — `OneOf<...>` discriminated unions and `Optional<T>` mirror the protocol's variant and optional fields

## Installation

### Requirements

- [.NET 10.0 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) or later

### Add to your project

```bash
dotnet add package ArkMirage.BedrockProtocol
```

Or add a project reference:

```xml
<ItemGroup>
  <ProjectReference Include="path/to/Protocol.csproj" />
</ItemGroup>
```

## Quick Start

### Decode an incoming packet

```csharp
using Protocol.Packets;

// packetId comes from your transport layer (e.g. a RakNet frame payload)
IPacket packet = PacketRegistry.CreatePacket(packetId);
packet.Decode(rawBytes);

if (packet is TextPacket chat)
{
    // Strongly-typed access to every field
}
```

### Build and encode an outgoing packet

```csharp
using Protocol.Packets;

var outgoing = new TextPacket
{
    // ...set properties...
};

ReadOnlyMemory<byte> bytes = outgoing.Encode();
```

## Project Structure

| Path | Description |
|------|-------------|
| `Codec/IPacket.cs` | Packet base class — handles the unsigned-varint ID prefix, `Encode` / `Decode`, and byte caching |
| `Codec/PacketRegistry.cs` | Static registry mapping packet IDs ↔ types, plus factory methods |
| `Codec/MinecraftPacketIds.cs` | Enum of all packet IDs |
| `Codec/Packet/` | One codec per packet (`LoginPacket`, `TextPacket`, `MovePlayerPacket`, ...) |
| `Codec/Nbt/` | NBT (Named Binary Tag) codec |
| `Utility/` | Binary IO (`MemoryStreamReader` / `MemoryStreamWriter`), `VarInt`, `OneOf`, `Optional<T>`, etc. |
